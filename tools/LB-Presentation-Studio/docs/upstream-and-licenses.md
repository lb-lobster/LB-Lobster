# Upstream Skill references and licensing

Checked 2026-10-13 from GitHub metadata:
- [gpt-image2-ppt-skills](https://github.com/JuneYaooo/gpt-image2-ppt-skills) — Apache-2.0. Editable mode requires a real PPTX render backend; default is image deck.
- [mono-color-skill](https://github.com/yanliudesign/mono-color-skill) — MIT. Generates prompt + image using agent image capability.
- [gc-minimal-zine-poster](https://github.com/LiamGvchi/gc-minimal-zine-poster) — MIT. Generates a prompt + rendered poster using an image-capable agent.
- [GordenSuperPPTSkills](https://github.com/GordenSun/GordenSuperPPTSkills) — custom attribution statement in README, standard license not confirmed. No code vendored here.
- [PptxGenJS](https://github.com/gitbrent/PptxGenJS) — MIT.

This project distributes **integration instructions**, not third-party source code. Individual upstream repos have their own prerequisites, API costs, maintenance, and licensing; inspect their README/SKILL before running. Image Skill outputs are not automatically editable PowerPoint shapes. Avoid presenting image-to-editable reconstruction as perfect or low-cost.
